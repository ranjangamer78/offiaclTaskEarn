# TaskEarn - Official Landing Page & APK Download Platform

Official high-conversion responsive landing page and direct APK download platform for **TaskEarn** mobile rewards application.

## 🚀 Features

- **Direct APK Downloads**: Instant downloads saved to phone file manager / downloads folder (`TaskEarn.apk`).
- **Interactive Phone Mockup Slider**: Full interactive preview of real app screens:
  - 🎰 Daily Spin (Spin Wheel Simulator)
  - 🎟️ Scratch & Win (Gold Rush Scratch Cards)
  - 🎲 Bones / Dice Game (Roll Simulator)
  - 📋 Daily Tasks & 7-Day Streaks
  - ⭐ Rewards & Promo Code Redemptions
  - 💰 Wallet & Cashout Gateways (eSewa, Free Fire Diamonds, Robux)
- **Fast & Modern Stack**: Built with React 19, TypeScript, Vite 6, and Tailwind CSS v4.
- **Legal & Support Ready**: Built-in modals for About, Privacy Policy, Terms & Conditions, and Contact Support (`taskearnoffical@gmail.com`).

## 🛠️ Tech Stack

- **Framework**: React 19 (Vite)
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4 (@tailwindcss/vite)
- **Icons**: Lucide React
- **Animations**: Motion

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
The production bundle will be generated in `dist/` and mirrored to `docs/`.

## 🌐 GitHub Pages Deployment

This project is configured to work out-of-the-box on GitHub Pages:
1. Push this repository to GitHub.
2. Go to your GitHub repository **Settings** → **Pages**.
3. Under **Build and deployment** → **Source**, you can choose either:
   - **GitHub Actions** (Recommended — builds and deploys automatically via `.github/workflows/deploy.yml`)
   - **Deploy from a branch** → Branch: `main` → Folder: `/docs` or `/ (root)`.
4. Your website will be live with full UI, interactive games, and APK downloads!
